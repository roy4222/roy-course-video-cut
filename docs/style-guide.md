# 風格：畫面與講法

這一季的對象是**完全沒學過機器學習的人**。每一集讓人覺得「我跟得上」，比塞更多名詞重要。

## 講法

- 一個名詞出現之前，先用一句人話加一個生活例子，然後才給中文正式名稱和英文。
- 例子要具體：垃圾信、整理衣櫃、模擬考、餐廳分工。少用「在實務上我們通常會…」這種沒有畫面的句子。
- 數字、英文縮寫、破音字，用 `L(字幕, say="實際念法")` 分開。字幕可以有 `max_depth`，嘴巴要念「最大深度」。
- 一集 **10 到 20 分鐘**。`build.py` 存檔時會用字數粗估（大約每個字 0.27 秒）。超過就拆集，不要念更快。
- 聲音要像老師在對新手講，不趕。套件預設就是這個語氣，見 [配音](tts-alignment.md)。

一集的節奏盡量固定，新手才知道等一下會發生什麼：

1. 開場提問（大約 30–60 秒，一個生活情境）
2. 今天的地圖（3 到 5 個詞，用 `chips`）
3. 直覺（先不要術語）
4. 名詞（人話 → 中文 → 英文）
5. 圖解（卡片、流程、表、樹）
6. 手算（數字一步一步出現）
7. 常見誤區
8. 小測驗大約 3 題（畫面可以倒數，觀眾可以暫停）
9. 重點回顧，以及下集預告
10. 和作業有關的集，最後加一段「這集對到作業的哪一步」

整季每一集要講哪些頁，寫在 `notes/season_plan.md`。那是規劃，不是講義本文。

## 畫面

風格叫做「暗色架構圖」：深色底、細格子、圓角卡片、少量藍和橘。

- 畫布 1920×1080。一種元素不要同時用太多顏色。`A` 藍是主線，`B` 橘是「現在看這裡」，`OK` / `BAD` 只用於對錯。
- 頁首放場景標題。內容留在中間。字幕在下方，所以 y 太低的字會被標成 UNDER-SUBTITLE。
- 同一句話不要在畫面上用另一種說法再寫一遍。字幕已經在念了，畫面放結構：表、箭頭、對照。
- 程式畫面（`code`）用在「這一行在做剛才那個步驟」。先看懂圖，再看程式。
- 字型要在每台電腦上看起來一樣，所以用倉庫裡的 Noto Sans CJK TC 和 DejaVu Sans Mono，不靠系統字型。Noto 要先下載，見 README。

## 聲音

- 預設：OpenRouter `google/gemini-3.8-flash-tts`，voice **Enceladus**。
- 台灣華語、清楚、友善、中等速度。提示句寫在 `windows-kit/kit/tts_openrouter.py` 的 `DEFAULT_INS`，也可以用環境變數 `KIT_TTS_INSTRUCTIONS` 覆寫。
- 選這個聲音的試聽紀錄在 `legacy/tools/voice_test/` 和 `notes/VOICE.md`。
- 成片要標明旁白是合成的。`yt` 步驟會在 `youtube.json` 放 `synthetic: true`。說明文字裡也寫「旁白為 AI 合成語音」。

## 標題與說明

- 標題形式：`機器學習從零開始 EPNN｜這集在講什麼`
- 說明 = 摘要 + 章節時間 + 系列的一段固定介紹。
- 介紹用「依照大學『機器學習』課程講義整理」這種說法。
- 不要在標題、標籤、說明裡寫學校名稱。上傳腳本會擋下來。
- 標籤用觀眾會搜的詞（決策樹、交叉驗證），加上系列名 `機器學習從零開始`。

## 作業集

A1、A2、EP20 這種實戰集要講清楚：畫面上的數字是方法示範，各組的資料和隨機種子不會一樣，作業要自己算。不要把整份作業解答做成可以直接交的稿。
