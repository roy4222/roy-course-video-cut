## 01. 同樣是讀書，方法不一樣

**講義**：PART01 p27–32  
**畫面**：cards

- 想像你要準備考試，有五種讀書法。
- 第一種，寫有解答的參考書，寫完就對答案。這叫監督式學習。
- 第二種，手上只有一堆題目、沒有解答，你只好自己把相似的題目歸成一類。這叫非監督式學習。
- 第三種，像打電動，沒人教你怎麼玩，但每做一個動作，就會加分或扣分。這叫強化學習。
- 第四種，老師只改了前十題，剩下幾百題你要自己想辦法。這叫半監督學習。
- 第五種，你把課本的字遮起來，自己考自己。這叫自監督學習。

## 02. 學習方式地圖

**講義**：PART01 p27–30  
**畫面**：table

- 講義把機器學習分成三大類：監督式、非監督式和強化學習，這三種到處都在用。
- 監督式的資料全部有標籤，學的是從輸入對到答案，常做分類和回歸。
- 非監督式沒有標籤，學的是資料裡的結構，像分群。
- 強化學習沒有標籤，但有獎勵，學的是該做什麼動作，像下棋和機器人。
- 後面兩種是介於中間的：半監督用少量標籤，加上大量沒標籤的資料；自監督則不靠人工標籤，自己從資料裡出題。

## 03. 監督式學習 Supervised Learning

**講義**：PART01 p33–36  
**畫面**：flow, compare

- 先看監督式學習。它是最常用的一種。
- 它的特色是：資料有標籤。標籤就是正確答案，像老師已經幫你批改好了。
- 例如一千張照片，每一張都寫好是貓還是狗。演算法看這些例子，找出照片和答案之間的關係。
- 學完以後，就得到一個訓練好的模型。
- 給它一張從沒看過的新照片，它就能說：這是貓。
- 監督式學習常做兩種任務：答案是類別的叫分類，答案是數字的叫回歸。這門課後半的決策樹、支援向量機，都是監督式學習。

## 04. Find the Bug：找找看哪裡怪？

**講義**：PART01 p37  
**畫面**：flow, note, note

- 講義第三十七頁有一題，叫 Find the Bug，要你找出圖裡的錯。
- 圖上畫的是監督式學習：輸入六顆番茄，經過演算法訓練，模型最後說：這是番茄！
- 先按暫停想一想，哪裡怪怪的？
- 問題在訓練資料。六張全部都是番茄，只有一種類別。模型從來沒看過不是番茄的東西，所以不管你給它什麼，它都可能說是番茄。
- 要修正，就要放進蘋果、草莓、紅色的球，並且標好答案。監督式學習想分辨幾種類別，每一類都要有例子。

## 05. 非監督式學習 Unsupervised Learning

**講義**：PART01 p38–41  
**畫面**：scatter, cards

- 再來是非監督式學習。它的資料沒有標籤。
- 想像你是一家咖啡店老闆，手上有每位客人的花費和來店次數，但沒有人告訴你，客人該分成哪幾種。
- 非監督式學習會自己找出隱藏的規律。
- 例如它發現，客人自然分成三群：一群常來但花得少，一群偶爾來但花很多，還有一群什麼都中等。
- 要注意，電腦只會分群，不會幫群取名字。而且它可能分出你想不到的群。這群是什麼意思，要由人來解讀。

## 06. 監督 vs 非監督

**講義**：PART01 p42  
**畫面**：compare

- 講義第四十二頁有一張漫畫，剛好可以比較兩者。
- 監督式學習，就像你拿著蘋果告訴機器人：這是蘋果。它的目標很明確，就是預測答案。
- 而且好評估，對一下答案就知道學得好不好。
- 非監督式學習，你只丟給機器人一堆水果說：把這些分一分。它可能照顏色分，也可能照大小分。
- 它的目標是找出結構，但因為沒有標準答案，評估比較困難。

## 07. 強化學習 Reinforcement Learning

**講義**：PART01 p43–50  
**畫面**：flow, note, note

- 第三種是強化學習。它沒有標籤，但有獎勵。
- 主角叫做代理人，英文是 agent，例如一台掃地機器人，或是一個下棋程式。
- 代理人看到現在的狀態，選一個動作去做，
- 環境就會給它回饋，也就是獎勵。撞到牆扣分，掃到垃圾加分。
- 它的目標，是讓長期累積起來的獎勵最大，而不是只看眼前這一步。就像下棋，有時候先犧牲一顆子，後面才能贏。
- 講義用了走迷宮和下圍棋當例子。代理人一開始亂走，慢慢從加分扣分裡，學會好的策略。
- 有名的 AlphaGo，就是先跟人類棋譜學，這是監督式；再自己跟自己對下學，這是強化學習。

## 08. 半監督學習 Semi-supervised

**講義**：PART01 p51–57  
**畫面**：cards

- 再來是半監督學習。為什麼需要它？因為標籤很貴。
- 例如醫療影像，要請醫生一張一張判讀。網路上的照片很多，但有標好答案的很少。
- 半監督學習，就是用少量有標籤的資料，加上大量沒有標籤的資料，一起訓練。它介於監督式和非監督式之間。
- 它背後有個基本假設：長得像的資料，答案通常也一樣。
- 但要小心：如果一開始猜錯，錯誤會越滾越大。所以講義提醒要做品質控制，只採用模型很有把握的猜測，還要留一些資料來驗證。

## 09. 例子：10 張照片只標 2 張

**講義**：PART01 p53–59  
**畫面**：flow, note

- 舉個例子。假設有十張貓狗照片，但只有兩張標了答案。
- 第一步，先用這兩張有標籤的照片，訓練出一個老師模型。
- 第二步，讓老師去猜剩下八張的答案。這些猜出來的答案，叫做偽標籤。
- 第三步，只留下老師很有把握的，例如六張。沒把握的先放著。
- 第四步，用原本的兩張，加上這六張，訓練一個學生模型，最後再用真的標籤微調。
- 這就是講義第五十八頁的老師學生法，英文是 Teacher Student。老師先教，學生從老師的筆記裡學到更多。

## 10. 自監督學習 Self-supervised

**講義**：PART01 p60–66  
**畫面**：statement, flow, note

- 最後是自監督學習。它的想法很聰明：自己出題、自己當答案。
- 例如一句話：今天天氣很什麼，我們去海邊玩。把一個字遮起來，讓模型猜。
- 答案「好」本來就在原文裡，完全不用人來標。這種自己出的題目，叫做前置任務。
- 這樣一來，網路上所有的文字，都可以變成練習題。
- 自監督學習通常分兩階段。第一階段是預訓練，在海量原始資料上，自己出題學通用的知識。
- 第二階段是微調，再用少量有標籤的資料，學會特定的任務。
- 有名的 BERT 是用遮字猜字訓練的，GPT 則是一直猜下一個字。它們都是自監督學習的成果。

## 11. 自監督的風險、品質控制與應用

**講義**：PART01 p67–68  
**畫面**：cards

- 不過，自監督學習也有風險。資料這麼多，難免帶有偏見，也可能不小心洩漏隱私，而且訓練要花很多計算成本。
- 所以要做品質控制：檢查資料來源，把訓練和驗證的資料分開，還要用外部資料驗證。
- 它的應用非常廣，包括大型語言模型、醫療影像、語音辨識、電腦視覺，還有時間序列分析。講義最後一句話總結：自監督學習，是從資料本身創造學習目標。

## 12. 常見誤會

**講義**：—  
**畫面**：cards

- 整理三個常見的誤會。
- 第一，非監督式學習不會告訴你每一群是什麼，它只負責分群，意思要由人來解讀。
- 第二，半監督不能亂猜偽標籤。錯誤會越滾越大，所以要挑有把握的，還要留驗證資料。
- 第三，自監督不是完全不需要人。預訓練不用人工標籤，但微調和品質控制，還是需要人。

## 13. 小測驗

**講義**：—  
**畫面**：quiz

- 來做小測驗。
- 第一題：用十萬筆已經知道有沒有違約的貸款紀錄，來預測新客戶會不會違約，是哪一種學習？（停頓 3.0 秒）
- 答案是監督式學習。資料有標籤，而且答案是類別，所以是分類。
- 第二題：掃地機器人撞牆就扣分、掃到垃圾就加分，慢慢學會打掃路線，是哪一種？（停頓 3.0 秒）
- 答案是強化學習。
- 第三題：把句子遮掉一個字，讓模型去猜，是哪一種？（停頓 3.0 秒）
- 答案是自監督學習。答案就藏在原文裡，不用人來標。
