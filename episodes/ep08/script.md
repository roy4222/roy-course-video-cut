## 00. 特徵工程與特徵選擇

**講義**：—  
**畫面**：title

- 嗨，歡迎回到機器學習從零開始，這是第八集。
- 上一集我們把資料整理乾淨了。今天的問題是：特徵那麼多，全部都要用嗎？還是挑一些就好？

## 01. 搬家打包：不是全部都要帶

**講義**：—  
**畫面**：cards, note

- 想像你要搬家。你會把家裡每一樣東西都打包嗎？
- 如果有兩支一模一樣的吹風機，帶一支就夠了。這叫重複。
- 舊家的停車證，到了新家完全用不到。這叫沒用。
- 還有一堆零碎的小東西，合成一箱來搬，就可以少跑好幾趟。
- 特徵工程也是一樣：丟掉重複的、丟掉沒用的，再把零碎的資訊整合起來。

## 02. 特徵工程的三件事

**講義**：PART02 p81–83  
**畫面**：flow

- 講義第八十三頁，把特徵工程整理成三件事。
- 第一，降維：把很多舊特徵，組合成少數幾個新特徵，同時保留最重要的資訊。
- 第二，特徵選擇：從原本的特徵裡，挑出有用的，丟掉重複和無關的。
- 第三，特徵建立：從原始資料，造出更能表達規律的新特徵。
- 講義也說，這些主題大致可以分成兩類：一類是決定要用哪些資料和欄位，另一類是創造或轉換欄位。

## 03. 為什麼要降維？維度詛咒

**講義**：PART02 p84–85  
**畫面**：cards

- 為什麼要降維？因為特徵可能非常多。
- 例如一堆文件，每一個字都可以是一個特徵；時間序列裡，每一天的股價也都是一個特徵，動不動就幾千個。
- 特徵太多，會遇到維度詛咒。維度越高，資料點在空間裡就越稀疏，
- 就像一個房間裡放十個人，很擠；但把十個人放在一座城市裡，彼此就離得很遠。這時候，用距離判斷誰跟誰像，就越來越沒意義。
- 降維的好處是：去掉無關的特徵和雜訊，很多演算法反而會更準，模型也比較好懂。
- 還有，資料更容易畫成圖，也能節省計算的時間和記憶體。

## 04. 降維 vs 特徵選擇；PCA 的直覺

**講義**：PART02 p85–86  
**畫面**：scatter, cards

- 先分清楚兩個名詞。講義說，降維通常指的是：用舊特徵的組合，做出新的特徵，也叫特徵萃取；而只挑出原本特徵的一部分，叫特徵選擇。
- 降維最有名的方法，是主成分分析，英文縮寫 PCA。
- 用一個直覺來理解。假設你有一群人的身高和體重，畫成散布圖，點大致排成一條斜斜的帶子。
- 與其用身高和體重兩個特徵，不如沿著這條帶子畫一條新的軸，叫它「體型大小」。只用這一個新特徵，就保留了大部分的資訊。
- 就像用手電筒照一個物體，從最能看出形狀的角度照，影子就能描述它。這就是 PCA 的想法：找出資料變化最大的方向。

## 05. 冗餘特徵與無關特徵

**講義**：PART02 p87  
**畫面**：compare, note

- 特徵選擇聽起來好像會損失資訊，但講義說，如果資料裡有冗餘和無關的特徵，就不會。
- 冗餘特徵，是它的資訊和其他特徵重複。例如同時有 BMI、身高和體重，
- BMI 本來就是從身高和體重算出來的，三個都放，就有重複。
- 無關特徵，是對任務完全沒幫助。例如用學號來預測學期成績，學號跟成績一點關係都沒有。
- 有些可以用常識直接刪掉，但大部分的情況，要靠有系統的方法。講義介紹了三種。

## 06. 特徵選擇三種方法

**講義**：PART02 p88–93  
**畫面**：table

- 第一種是 Filter，過濾法。它在訓練模型之前，就先幫特徵打分數，例如用相關係數、卡方檢定或資訊增益。它跟後面用什麼模型完全無關。
- 好處是最快，適合特徵超級多的時候，先過濾掉明顯沒用的。
- 第二種是 Wrapper，包裝法。它把模型當成黑盒子，一直重複呼叫：試這組特徵，看準確率；再換一組，看準確率。常見的做法有前向選擇和後向刪除。
- 它通常最準，但計算成本非常大，也比較容易過擬合。
- 第三種是 Embedded，嵌入法。特徵選擇在模型訓練的過程中，自然發生。
- 例如 LASSO 會把不重要特徵的權重壓成零；決策樹則會直接告訴你每個特徵有多重要。它結合了過濾法的效率，和包裝法的準確。
- 講義第九十一、九十二頁有完整的比較圖，這張表就是它的重點整理。

## 07. 用「招募員工」記住三種方法

**講義**：—  
**畫面**：cards, note

- 三種方法有點抽象，我們用公司招募員工來記。
- Filter 像是看履歷篩選：還沒面試，就先依照學歷、證照打分數，把明顯不合的刪掉。很快，但不知道這些人實際合不合作。
- Wrapper 像是讓不同的人組成小組，實際做一個專案，看哪一組成績最好。很準，但非常花時間。
- Embedded 像是先全部錄取，在工作的過程中，自然看出誰很重要、誰可有可無。
- 實務上常見的做法是：先用 Filter 粗篩，把特徵數量降下來，再用 Wrapper 或 Embedded 精挑。

## 08. 練習：5 個特徵挑 2 個

**講義**：—  
**畫面**：table, table

- 來練習。我們想預測期末成績，手上有五個特徵：讀書時數、出席率、讀書分鐘數、身高和學號。只能挑兩個。
- 先用 Filter。算每個特徵和成績的相關係數。假設算出來是畫面上這樣。
- 讀書時數零點八，出席率零點六，都很高，先保留。
- 讀書分鐘數也是零點八，但它只是時數乘以六十，是冗餘的。身高和學號幾乎是零，是無關的，刪掉。
- 再用 Wrapper 驗證一次。直接拿模型試不同組合，假設結果是這樣：只用讀書時數，準確率百分之七十；加上身高，只多一點點。
- 加上出席率，跳到百分之八十二，是最好的組合。兩種方法的結論一致：選讀書時數和出席率。

## 09. 特徵建立：萃取與轉換到新空間

**講義**：PART02 p94–97  
**畫面**：cards, note

- 最後是特徵建立。講義介紹了兩種做法。
- 第一種是特徵萃取。例如要判斷照片裡有沒有人臉，原始資料是一大堆像素，很多演算法沒辦法直接用。
- 如果先萃取出比較高階的特徵，例如有沒有某些邊緣和輪廓，就容易多了。
- 第二種是把資料轉換到新的空間。例如一段有很多雜訊的時間序列，直接看，完全看不出週期。用傅立葉轉換，把它換成頻率來看，主要的頻率就會變成明顯的高峰。
- 講義也提醒，特徵萃取很依賴領域知識；而且新特徵的數量可以比原本少，順便也達到了降維的效果。

## 10. 常見誤會

**講義**：—  
**畫面**：cards

- 三個常見的誤會。
- 第一，特徵越多，模型越準。不一定，冗餘和無關的特徵會變成雜訊。
- 第二，降維和特徵選擇是同一件事。不是，降維是造新的特徵，特徵選擇是挑舊的特徵。
- 第三，Wrapper 最準，所以永遠用它。它的計算量非常大，也容易過擬合，特徵很多的時候，通常先用 Filter 過濾一輪。

## 11. 小測驗

**講義**：—  
**畫面**：quiz

- 小測驗。
- 第一題：PCA 是在造新的特徵，還是挑舊的特徵？（停頓 3.0 秒）
- 答案是造新的特徵。它把舊特徵組合起來，屬於降維，也叫特徵萃取。
- 第二題：決策樹在訓練的時候，自己算出每個特徵有多重要，這是哪一種特徵選擇方法？（停頓 3.0 秒）
- 答案是 Embedded，嵌入法。
- 第三題：資料裡同時有攝氏溫度和華氏溫度兩個特徵，這叫什麼？（停頓 3.0 秒）
- 答案是冗餘特徵。華氏可以直接從攝氏換算，留一個就好。

## 12. 重點回顧

**講義**：—  
**畫面**：recap

- 重點回顧。
- 特徵工程有三件事：降維、特徵選擇和特徵建立。
- 特徵太多會遇到維度詛咒，資料變稀疏，距離變得沒意義。
- PCA 找出資料變化最大的方向，造出新的特徵。
- 要刪掉冗餘特徵，例如 BMI 和身高體重；也要刪掉無關特徵，例如學號。
- 特徵選擇有三種方法：Filter 最快，Wrapper 最準但很貴，Embedded 兩者兼顧。
