**講義**：—

## 01. 兩筆資料，有多像？

**講義**：PART02 p98–101  
**畫面**：compare, note

- 在網路書店買書，網站會說：買了這本書的人，也買了那本。它怎麼知道兩本書，或是兩位客人很像？
- 答案是：把「像不像」變成一個數字。講義說，很多機器學習方法，都要用到相似度和相異度。
- 相似度，是越大越像，通常介於零到一，一代表完全一樣。
- 相異度則是越大越不像，最常見的就是距離。最小是零，上限不一定。
- 講義也先預告：文件這種稀疏資料，常用 Jaccard 和 Cosine；數值點和時間序列這種密集資料，常用歐氏距離和相關係數。

## 02. 歐氏距離 Euclidean Distance

**講義**：PART02 p102–103  
**畫面**：scatter, formula

- 最常用的距離，是歐氏距離，也就是我們最熟悉的直線距離。
- 講義第一百零三頁有四個點：p1 是零、二，p2 是二、零，p3 是三、一，p4 是五、一。
- 歐氏距離的公式是：每個維度相減、平方、加總，最後開根號。其實就是國中學過的畢氏定理。
- 來算 p1 到 p2：零減二是負二，平方是四；二減零是二，平方也是四。加起來八，開根號約等於二點八三。
- 再算 p1 到 p4：零減五，平方二十五；二減一，平方一。加起來二十六，開根號約五點一零。
- 把每一對點的距離都算出來，排成一張表，就叫距離矩陣。
- 特別提醒：如果各個屬性的單位差很多，例如公分和元，一定要先標準化，不然大的數字會主宰整個距離。

## 03. Minkowski 距離：r = 1、2、∞

**講義**：PART02 p104–107  
**畫面**：table, note

- 歐氏距離其實是一個大家族的成員，這個家族叫 Minkowski 距離。它有一個參數 r。
- 公式是：每個維度相減取絕對值，取 r 次方，加總，再開 r 次方根。r 不同，就得到不同的距離。
- 當 r 等於一，叫曼哈頓距離，也叫計程車距離。想像在台北的棋盤式街道上走路，不能斜穿大樓，只能橫著走再直著走。p1 到 p2，就是二加二，等於四。
- 當 r 等於二，就是剛剛的歐氏距離，像鳥直線飛過去，約二點八三。
- 當 r 趨近無限大，叫上確界距離，只看差最多的那一個維度。p1 到 p2 兩個維度都差二，所以是二。
- 講義提醒，r 是參數，n 是維度數，不要搞混。另外，曼哈頓距離用在二元資料上，就叫漢明距離，也就是兩串零一，有幾個位置不一樣。

## 04. 二元資料：SMC vs Jaccard

**講義**：PART02 p108–109  
**畫面**：formula, note

- 如果資料只有零和一兩種值，要怎麼算相似度？講義介紹了兩種。
- 舉個例子，x 和 y 是兩位客人，十種商品裡，有買是一，沒買是零。
- 先數四種情況：兩個都是一的，有零個；x 是一、y 是零的，有一個；x 是零、y 是一的，有兩個；兩個都是零的，有七個。
- 第一種是簡單匹配係數，SMC，就是「一樣的個數」除以全部。一樣的有零加七，等於七，除以十，是零點七。
- SMC 把「都有」和「都沒有」看得一樣重，適合像是非題答案這種對稱的資料。
- 第二種是 Jaccard 係數，只看至少有一方是一的位置：分子是兩個都是一的個數，是零；分母是零加一加二，等於三。所以 Jaccard 是零。
- 你看，SMC 說他們很像，Jaccard 說完全不像。哪個對？想想上一集的不對稱屬性：兩個人都沒買魚子醬，不代表他們很像。購物籃這種資料，應該用 Jaccard。

## 05. Cosine 相似度

**講義**：PART02 p110–115  
**畫面**：formula, note

- 再來是文件。一篇文章可以表示成一個向量，每個位置是某個字出現的次數。大部分的字都沒出現，所以很稀疏。
- 講義第一百一十二頁有兩篇文件 d1 和 d2。
- Cosine 相似度的想法是：看兩個向量的夾角，而不是長度。所以一篇長文章和一篇短文章，只要用字比例很像，就算很像。
- 先算內積：對應位置相乘再相加。只有第一個和第八個位置兩邊都不是零：三乘一加二乘一，等於五。
- 再算各自的長度：d1 是根號四十二，約六點四八一；d2 是根號六，約二點四四九。
- Cosine 就是內積除以兩個長度相乘：五除以六點四八一乘二點四四九，約等於零點三一五。
- Cosine 等於一，代表方向完全一樣，只差長短；等於零，代表夾角九十度，兩篇文章沒有共同的字。

## 06. 相關係數：線性 vs 非線性

**講義**：PART02 p116–118  
**畫面**：scatter, cards

- 相關係數，衡量的是兩組數值之間的線性關係，例如身高和體重，或是兩個城市的氣溫時間序列。
- 它介於負一到一。一是完全正相關，負一是完全負相關，零是沒有線性關係。
- 但要特別小心。講義第一百一十八頁舉了一個例子：
- x 從負三到三，y 等於 x 的平方。畫出來是一個漂亮的 U 形。
- 算出來的相關係數，竟然是零！可是 y 明明完全由 x 決定。
- 所以，相關係數是零，不代表沒有關係，只代表沒有直線的關係。講義也補充：只有在兩個向量的平均都是零的時候，相關係數才會等於 Cosine。

## 07. Entropy：混亂度

**講義**：PART02 p119–124  
**畫面**：cards, formula

- 接著是 Entropy，中文叫熵。它原本是物理名詞，粒子到處亂跑，熵就很高。在資訊理論裡，它代表混亂的程度，也可以說是不確定性。
- 用摸球來想。一袋子裡全是紅球，閉著眼睛也知道會摸到紅球，完全不混亂，Entropy 是零。講義說這叫最純。
- 如果紅球藍球各一半，你完全猜不到，Entropy 最大；八紅兩藍，大概猜得到，就介於中間。
- Entropy 的公式是：負的，每一類的機率 p，乘以以二為底的 log p，再全部加起來。
- 例如一枚公平的硬幣，正反面各一半，算出來 Entropy 剛好是一。
- 如果硬幣永遠是正面，p 等於一，log 一是零，Entropy 就是零。之後決策樹，就是要找出讓 Entropy 降最多的切法。

## 08. 例題：髮色的 Entropy

**講義**：PART02 p121–122  
**畫面**：table, note

- 來算講義第一百二十二頁的例題：一百個人的髮色。
- 黑髮七十五人，棕髮十五人，金髮五人，紅髮零人，其他五人。先把人數除以一百，得到機率 p。
- 黑髮的 p 是零點七五。log 二的零點七五，約是負零點四一五，乘上零點七五再加負號，得到零點三一一三。
- 棕髮 p 是零點一五，算出來零點四一零五。金髮和其他都是零點零五，各是零點二一六一。
- 紅髮人數是零，我們規定零乘 log 零等於零，所以不用算。
- 全部加起來：零點三一一三，加零點四一零五，加兩個零點二一六一，總共約一點一五四。
- 五類最混亂的時候，Entropy 是 log 二的五，約二點三二。一點一五四代表：大部分人是黑髮，但還不算很純。

## 09. 相互資訊 Mutual Information

**講義**：PART02 p125–131  
**畫面**：formula, cards, formula

- 有了 Entropy，就能定義相互資訊，英文是 Mutual Information。它衡量的是：一個變數，能提供多少關於另一個變數的資訊。
- 講義說，它常被拿來代替相關係數，特別是懷疑兩者有非線性關係的時候。
- 公式是：X 的 Entropy，加 Y 的 Entropy，減掉兩者一起的聯合 Entropy。
- 如果兩個變數互相獨立，知道 X 對猜 Y 完全沒幫助，相互資訊就是零；如果完全相依，知道 X 就知道 Y，相互資訊最大。
- 剛剛 y 等於 x 平方的例子，相關係數是零，但相互資訊不是零，它抓得到這種非線性的關係。講義第一百三十一頁，就用這組資料算了一次。
- 七個 x 都不一樣，各佔七分之一，所以 X 的 Entropy 是 log 二的七，約二點八零七四。y 只有零、一、四、九四種值，零出現一次，其他各出現兩次，算出來約一點九五零二。
- 每一對 x 和 y 也都不一樣，所以聯合 Entropy 也是二點八零七四。相互資訊就是二點八零七四，加一點九五零二，減二點八零七四，等於一點九五零二。
- 講義再把它除以 log 二的四，也就是兩邊比較少的值的個數取 log，正規化以後約零點九七五，非常接近一。代表知道 x，幾乎就知道 y。相關係數說沒關係，相互資訊卻說關係很強。

## 10. 怎麼選對的量測方式？

**講義**：PART02 p132–141  
**畫面**：table, note

- 最後，這麼多量測方式，要怎麼選？講義第一百三十三頁說：首先，量測方式要配合資料的型態。
- 密集的連續數值，常用歐氏距離，記得先標準化。
- 稀疏又不對稱的資料，例如購物籃，用 Jaccard，只看兩邊都有的，忽略都沒有的。
- 文件用 Cosine，因為它只在乎用字的比例，不在乎文章長短。
- 時間序列常用相關係數，因為它不受整體放大和平移的影響。時間序列還要注意趨勢、週期和時間落差。
- 懷疑有非線性關係，就用相互資訊。
- 最後，也要考慮各領域的習慣。如果沒有慣例，就要多試幾種，看哪一種的結果最合理。講義最後也說，這個主題沒有單獨的作業，但期末報告可以用上這個單元的方法。

## 11. 常見誤會

**講義**：—  
**畫面**：cards

- 三個常見的誤會。
- 第一，不標準化就直接算距離。收入幾十萬、身高一百多，距離幾乎只看收入。
- 第二，購物籃資料用 SMC。「都沒買」會被算成很像，應該用 Jaccard。
- 第三，相關係數是零，就是沒關係。可能有非線性關係，例如 y 等於 x 平方。

## 12. 小測驗

**講義**：—  
**畫面**：quiz

- 小測驗，請拿出紙筆。
- 第一題：點 A 是一、一，點 B 是四、五。歐氏距離和曼哈頓距離各是多少？（停頓 5.0 秒）
- 答案是：兩個維度分別差三和四。歐氏距離是根號九加十六，等於五；曼哈頓距離是三加四，等於七。
- 第二題：一袋四顆球，兩紅兩藍，Entropy 是多少？（停頓 4.0 秒）
- 答案是一。紅藍各一半，跟公平硬幣一樣，是兩類時最混亂的情況。
- 第三題：要比較兩篇長短不同的新聞，用字像不像，該用哪一種量測？（停頓 3.0 秒）
- 答案是 Cosine 相似度。

## 13. 重點回顧

**講義**：—  
**畫面**：recap

- 重點回顧。
- 相似度越大越像；相異度，例如距離，越大越不像。
- Minkowski 距離家族：r 等於一是曼哈頓，二是歐氏，無限大是上確界。單位不同要先標準化。
- 二元資料，SMC 看全部，Jaccard 忽略都是零的位置，適合購物籃。
- Cosine 看方向，適合文件；相關係數只抓線性關係。
- Entropy 是負的 p 乘 log p 的總和，越純越小。講義的髮色例子，答案是一點一五四。
