## 01. 先想想：哪一杯「最混」？

**畫面**：三杯飲料：全珍珠、大多珍珠、珍珠椰果各半  
**講義**：PART03 p68、p71

- [0:31] 想像你點了三杯飲料，每杯裡面有六顆配料。
- [0:37] 第一杯，六顆全部是珍珠。
- [0:42] 第二杯，五顆珍珠、一顆椰果。
- [0:47] 第三杯，三顆珍珠、三顆椰果，一半一半。
- [0:54] 哪一杯最「混」？一定是第三杯；哪一杯最「純」？是第一杯。
- [1:02] 決策樹想要的，就是每切一刀，每一杯都越純越好，因為純的那杯一看就知道答案。
- [1:12] 所以問題變成：怎麼用一個數字，量出一杯有多「混」？

## 02. 長一棵樹的兩個大問題

**畫面**：兩張卡：分裂準則（怎麼切）、停止準則（何時停）  
**講義**：PART03 p60–62

- [1:19] 講義把長樹要決定的事，整理成兩個大問題。
- [1:25] 第一個問題：每一步要怎麼切？也就是要選哪個屬性、怎麼把資料分到子節點。
- [1:35] 這叫「分裂準則」，英文是 splitting criterion。今天整集都在講它。
- [1:45] 第二個問題：什麼時候停？上一集說，全部同一類就停，或是特徵全部一樣、分不開也只好停。
- [1:58] 但為了不要讓樹長得太大，有時候還沒純就先停，這叫「停止準則」，英文是 stopping criterion。這個我們留到剪枝那一集。

## 03. 屬性測試條件：不同型態，不同切法

**畫面**：四種屬性型態各自的切法；順序屬性的錯誤分組打叉  
**講義**：PART03 p63–67

- [2:14] 在算分數之前，先看看「一個問題可以怎麼問」。這要看屬性是什麼型態。
- [2:23] 二元屬性，例如有沒有房子，只有兩種答案，就切成兩邊。
- [2:31] 名目屬性，例如婚姻有單身、已婚、離婚，可以一次切三邊，叫多路分裂；也可以分成兩組，叫二元分裂。
- [2:47] 順序屬性，例如襯衫尺寸小、中、大、特大，有大小順序。分組的時候不能打亂順序。
- [3:00] 小和中一組、大和特大一組，可以；但小和大一組、中和特大一組，就把順序打亂了，不行。
- [3:11] 連續屬性，例如年收入，通常問「有沒有小於某個值」，切成兩邊；也可以切成好幾個區間。

## 04. 為什麼要「越純越好」？

**畫面**：純子節點 → 少分幾層 → 樹小 → 不易過擬合、好解釋  
**講義**：PART03 p68–70

- [3:25] 為什麼切完要越純越好？
- [3:30] 因為節點純了就不用再分；很混就還要再問好幾層，樹就會變大。
- [3:40] 講義提醒，大樹有三個缺點。
- [3:44] 比較容易過擬合，也就是連雜訊都背下來；比較難解釋；訓練和預測也比較慢。
- [3:55] 所以挑問題的原則就是：選能讓子節點「最純」的那個問題。

## 05. 名詞：不純度與三種量法

**畫面**：三條公式一行一行出現，p 的意義說明  
**講義**：PART03 p71

- [4:04] 「一個節點有多混」，正式名稱叫做「不純度」，英文是 impurity。數字越大越混，零就是完全純。
- [4:18] 要算不純度，先算每個類別的比例。p 下標 i，就是這個節點裡，第 i 類佔的比例。
- [4:28] 例如第二杯，五顆珍珠、一顆椰果，珍珠的比例是六分之五，椰果是六分之一。
- [4:40] 第一種量法叫 Entropy，中文是「熵」，第九集看過。公式是：負的，每一類的比例乘上 log 以二為底的比例，全部加起來。
- [4:56] 第二種叫 Gini 不純度，Gini index。公式是：一減掉每一類比例的平方和。白話說，隨便抽兩顆，抽到不同類的機會有多大。
- [5:12] 第三種叫分類錯誤率，classification error。公式是：一減掉最大的那個比例。白話說，如果全部猜最多的那類，會猜錯多少。
- [5:29] 有一個小規定：算 Entropy 的時候，比例是零的那一項，就當作零，不用管 log 零。

## 06. 手算：三杯的不純度

**畫面**：講義 p73：(0,6)、(1,5)、(3,3) 三個節點三種指標逐步計算  
**講義**：PART03 p72–73

- [5:39] 來手算講義第七十三頁的三個節點，就是剛剛那三杯。
- [5:45] 第一杯是零和六，全部同一類。三種量法都等於零，完全純。
- [5:55] 第二杯是一和五。Gini 是一減六分之一的平方、再減六分之五的平方，也就是一減三十六分之二十六，等於零點二七八。
- [6:12] Entropy 是負的六分之一乘 log 二的六分之一，再減六分之五乘 log 二的六分之五，大約零點四三一加零點二一九，等於零點六五零。
- [6:33] 分類錯誤率是一減六分之五，等於零點一六七。
- [6:42] 第三杯是三和三，一半一半。Gini 是一減零點二五、再減零點二五，等於零點五；Entropy 等於一；錯誤率也是零點五。
- [7:01] 你會發現，三種量法排出來的順序都一樣：第一杯最純，第三杯最混。講義說這叫三種量法的「一致性」。
- [7:16] 而且兩類的時候，最混就是一半一半：Entropy 最大是一，Gini 和錯誤率最大是零點五。

## 07. 切完以後：子節點要「加權平均」

**畫面**：公式 I(children) = Σ N(vj)/N · I(vj)；兩班平均分數的比喻  
**講義**：PART03 p74–75

- [7:29] 一刀切下去，會變成好幾個子節點。那「切完以後整體有多混」，要怎麼算？
- [7:38] 想像兩個班一起算平均分數：一班四十人平均八十分，另一班十人平均六十分。
- [7:49] 合起來的平均，不是八十加六十除以二，而是要按人數加權：四十個人的那班，份量比較重。
- [8:02] 四十乘八十，加十乘六十，除以五十，等於七十六分。
- [8:15] 子節點的不純度也是一樣：每個子節點的不純度，乘上它佔的資料比例，再加起來。
- [8:26] 寫成公式：子節點的整體不純度，等於每個子節點的筆數除以總筆數，乘上它的不純度，全部加總。

## 13. 陷阱：用 ID 來切，最純？

- [17:36] 加權不純度等於零，增益最大。照剛剛的規則，ID 竟然是最好的問題！

## 14. Gain Ratio：懲罰切太多塊

**畫面**：Split Info 與 Gain Ratio 公式；Gender 0.029、Car Type 0.41、ID 0.23  
**講義**：PART03 p95–97

- [18:27] Gain Ratio 的做法是：拿資訊增益，除以一個叫做 Split Info 的數字。
- [18:35] Split Info 中文可以叫「分裂資訊」。它其實就是把「每個子節點分到幾成資料」拿來算 Entropy。
- [18:49] 切成越多塊、每塊又差不多大，Split Info 就越大，除下去，Gain Ratio 就變小。這就是懲罰。
- [19:00] 來算講義第九十七頁的例子。資料是二十筆，C0 和 C1 各十筆，父節點 Entropy 等於一。
- [19:12] 用性別切：子節點加權 Entropy 是零點九七一，增益零點零二九。男女各十筆，Split Info 等於一，所以 Gain Ratio 是零點零二九。
- [19:28] 用車子種類切：子節點加權 Entropy 是零點三八，增益零點六二。分成四筆、八筆、八筆三塊，Split Info 是一點五二，Gain Ratio 是零點四一。
- [19:48] 用 ID 切：增益是一，最大。但二十筆切成二十塊，Split Info 是 log 二的二十，大約四點三二，Gain Ratio 只剩零點二三。
- [20:04] 所以雖然 ID 的資訊增益最大，它的 Gain Ratio 卻比車子種類低。最後選車子種類，陷阱解除。

**講義**：PART03 p71–97

- [21:17] 整理幾個最常見的錯誤。
- [21:20] 第一，Entropy 的 log 要用以二為底，計算機要記得換底。
- [21:28] 第二，子節點要用「筆數比例」加權，不能直接把幾個子節點的不純度平均。
- [21:38] 第三，兩類的時候，Gini 最大只有零點五，不是一；Entropy 最大才是一。
- [21:47] 第四，選問題是看「增益最大」，也就是「加權不純度最小」，不要把方向弄反。
- [21:58] 第五，連續屬性的切點要算，最好的切點常常跟直覺不一樣。
- [22:06] 第六，看到 ID 這種每筆都不一樣的屬性，增益很高也不要高興太早，要想到 Gain Ratio。

## 17. 小測驗

**畫面**：三題，倒數暫停後揭曉  
**講義**：—

- [22:18] 來個小測驗，可以先暫停，拿紙筆算一算。
- [22:23] 第一題：一個節點是二逗二，它的 Gini 是多少？（停頓 4 秒）
- [22:34] 一減零點五的平方、再減零點五的平方，等於零點五。這是兩類時最混的情況。
- [22:46] 第二題：父節點都一樣，屬性 A 切完的加權 Entropy 是零點四，屬性 B 是零點六，該選哪一個？（停頓 3 秒）
- [23:02] 選 A。加權不純度越小，增益就越大。
- [23:09] 第三題：為什麼 C4.5 要用 Gain Ratio，而不是只看資訊增益？（停頓 3 秒）
- [23:21] 因為資訊增益偏好切很多塊的屬性，像 ID；Gain Ratio 用 Split Info 懲罰切太多塊。
